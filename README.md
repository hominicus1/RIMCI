# RIMCI

**RIMCI** — otwarty katalog składników suplementów, adaptogenów i substancji pomocniczych.

## Aktualny etap: alpha

- Katalog składników z wyszukiwarką i kategoriami.
- Rozpoznawanie nazw i numerów E z etykiety.
- Lista posiadanych substancji (lokalnie w przeglądarce).
- Rozróżnienie funkcji technologicznej od oceny bezpieczeństwa.
- Podstawy pod przyszłą bazę produktów, interakcji i planer dawkowania.

**Ważne:** RIMCI nie jest jeszcze narzędziem do indywidualnego dawkowania. Nie należy wyznaczać dawek wyłącznie na podstawie nazw produktów. Oceny składników są opisowe i zależą od ilości, zastosowania, indywidualnych przeciwwskazań i aktualnych regulacji.

## Uruchomienie

Otwórz `index.html` w przeglądarce. Nie potrzeba serwera ani instalacji.

## Struktura

- `index.html` — interfejs
- `src/app.js` — wyszukiwarka, analizator etykiet, lista posiadanych
- `src/styles.css` — wygląd
- `data/ingredients.js` — początkowy katalog i synonimy

## Plan rozwoju

Pełna baza składników aktywnych i pomocniczych, mechanizmy działania, siła dowodów, interakcje, produkty producentów, sumowanie dawek, źródła i weryfikacja danych, plan suplementacji z uwzględnieniem leków i przeciwwskazań.
